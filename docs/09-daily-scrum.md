# 9. Daily scrum template for AI-heavy teams

This is designed to prevent fake progress.

---

# Daily Scrum Update

## Yesterday

I worked on:

- [Concrete work completed]

Evidence:

- [PR link / commit / test result / document / decision]

## Today

I will work on:

- [Concrete work planned]

Expected output:

- [What should exist by the next check-in]

## Blockers

I am blocked by:

- [Blocker 1]
- [Blocker 2]

I need help from:

- [Person/team]

## Understanding Check

My current understanding of the ticket is:

> [Explain intent in 1–3 sentences.]

## AI Usage

AI helped me with:

- [ ] Understanding
- [ ] Coding
- [ ] Testing
- [ ] Debugging
- [ ] Documentation
- [ ] Review
- [ ] Not used

I have verified:

- [ ] The AI output matches the ticket intent
- [ ] The AI output is technically correct
- [ ] I know what I am committing
- [ ] I know what still needs human review
