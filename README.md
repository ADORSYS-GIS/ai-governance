# AI Delivery Governance — Scrum Artifacts

Copy-paste-ready Scrum artifacts for an AI-heavy team. These templates add the
discipline layer that golden paths and tooling do not: **human accountability,
verification, and intent preservation**.

> **AI may accelerate the work, but it must not launder ignorance into polished artifacts.**

## The Artifact Is Not The Thinking

A ticket is not understanding.
A summary is not reading.
A generated test is not verification.
A code diff is not delivery.
A review comment is not judgment.

AI can help us move faster, but it must not become a machine for producing confident nonsense.

Every artifact must have a human owner.
Every important claim must have evidence.
Every ticket must preserve intent.
Every completed task must be verified.
